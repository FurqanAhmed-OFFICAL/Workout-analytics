## 📌 Overview
This project analyzes the **[600K+ Fitness Exercise & Workout Program Dataset](https://www.kaggle.com/datasets/adnanelouardi/600k-fitness-exercise-and-workout-program-dataset)** and builds an **interactive Power BI dashboard** for workout planning.  

The goal is to help users filter and choose workout routines based on **equipment availability, experience level, and duration**.
