# 🏋️‍♂️ Fitness Workout Program Dashboard

## 📌 Overview
Interactive Power BI dashboard built on the [600K+ Fitness Exercise & Workout Program Dataset](https://www.kaggle.com/datasets/adnanelouardi/600k-fitness-exercise-and-workout-program-dataset).  
The dataset (~600k rows) includes workout programs, exercises, difficulty levels, equipment types, and durations.  

## ⚙️ Tools & Workflow
- **SQL**: Data cleaning, extraction, and SQL views  
- **Power Query**: Dynamic ETL process  
- **Power BI (DAX)**: Measures, KPIs, and interactive visuals  

## 🎯 Features
- Filter programs by **equipment**, **experience level**, and **duration**  
- Drill-down into **workout routines** (exercise name, sets/reps, training volume)  
- Optimized queries for smooth performance on 600k+ records
